# CRUD de Personas

API REST desarrollada con Flask. Las personas se almacenan en memoria mientras
la aplicación está en ejecución; los datos se reinician al volver a iniciarla.

## Estructura del proyecto

```text
Proyecto (propio)/
├── api.py
├── consigna
├── model/
│   └── persona.py
├── readme.md
├── receta
├── repository/
│   └── personas_repository.py
├── requirements.txt
└── service/
	└── personas_service.py
```
